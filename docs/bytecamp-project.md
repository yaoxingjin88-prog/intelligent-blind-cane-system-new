# 智能盲杖系统 - 简历项目经历参考

## 项目名称

**智能盲杖 IoT 管理系统 (Intelligent Blind Cane System)**

## 项目简介

基于 ESP32 硬件 + Spring Boot 后端 + Vue 3 管理端 + Uni-app 微信小程序的全栈 IoT 项目，面向视障人士及其监护人提供实时定位、电子围栏、AI 语音助手、路口安全通行辅助等功能。

## 技术栈

| 层级 | 技术 |
|------|------|
| 管理端前端 | Vue 3 + TypeScript + Vite + Element Plus + ECharts + 高德地图 |
| 小程序端 | Uni-app (Vue 3) + uView Plus + Pinia + Sass |
| 后端 | Spring Boot 3.3 + MyBatis + MySQL 8 + JWT + WebSocket |
| AI/视觉 | DeepSeek 大模型 API + OpenCV + 百度语音 STT/TTS |
| 硬件 | ESP32 + 超声波/IMU/GPS 传感器 |

## 我负责的前端模块

### 1. 管理端数据看板（Dashboard）

- 使用 ECharts 实现活跃时长趋势折线图、设备电量柱状图、报警类型分布饼图
- 集成高德地图 JS API 绘制**风险区域热力图**，标注 Top 5 高风险热点
- 设计 6 项关键指标卡片（总设备数、在线率、今日报警、活跃用户等）
- 实现设备健康度面板与报警排行列表

### 2. 实时监控中心（Monitoring Center）

- 基于高德地图实现多设备实时位置分布图，支持地图点位聚合
- 设计多维度筛选器：关键字搜索 + 在线/离线 + 告警状态 + 测试状态
- 点击地图点位弹出设备详情卡片，支持快捷跳转轨迹回放
- WebSocket 接入实时告警推送，设备状态动态刷新

### 3. 单设备实时监控（Real-Time Monitor）

- 设备级地图定位 + 实时传感器数据面板（超声波距离、IMU 倾斜、GPS 精度）
- 报警信息实时展示，支持 WebSocket 推送

### 4. 电子围栏管理（Fences）

- 高德地图上可视化绘制圆形/矩形围栏，支持鼠标交互创建与编辑
- 围栏列表管理：启停控制、越界状态标记、批量筛选
- 越界设备通过 WebSocket 实时标红告警

### 5. 轨迹回放系统（Trajectory Playback）

- 基于高德地图绘制设备历史轨迹折线，标注起点/终点/当前位置
- 实现播放控制器：播放/暂停/重播，4 档速度（慢速/标准/快速/极速）
- 进度条支持拖拽跳转，同步更新地图位置和时间标签
- 统计卡片展示总里程、平均速度、最高时速、定位点数

### 6. 微信小程序 - AI 明眼助手

- 集成 DeepSeek 大模型 API，实现 SSE 流式消息渲染
- 支持语音输入（百度 STT）+ 自动朗读回复（百度 TTS）
- 实现连续对话模式：自动录音-识别-发送-朗读循环
- 内置快捷问题卡片，消息气泡支持复制/朗读操作

### 7. 微信小程序 - 路口安全通行辅助

- 实时展示红绿灯状态、斑马线检测结果、车辆接近预警
- WebSocket 接收后端视觉分析结果，给出 WAIT/GO/CAUTION 通行建议
- 支持语音播报 + 手机震动提醒，适配无障碍交互

### 8. 微信小程序 - 基础模块

- 电子围栏管理页：监护人远程设置安全区域
- 设备管理页：设备绑定、解绑、状态查看
- 报警管理页：告警列表、详情查看、处理状态更新
- 个人中心：免打扰设置、意见反馈、系统设置

### 9. 公共能力

- Axios 请求封装：JWT Token 注入、401 自动跳登录、请求/响应拦截
- Vue Router 路由守卫：未登录拦截 + 双重鉴权
- 小程序端 Pinia 状态管理：alarm / device / elder / settings 四个 store
- 小程序端 14 个 API 模块统一封装

## 前端技术亮点（简历可用描述）

### 亮点 1：IoT 数据可视化看板

> 基于 ECharts + 高德地图实现多维数据看板，包含风险热力图、趋势折线图、电量柱状图、报警饼图等 6 种图表，支持 Top 5 风险热点标注与设备健康度面板。

### 亮点 2：高德地图深度集成

> 在监控中心、围栏管理、轨迹回放三大模块中深度集成高德地图 JS API，实现多设备点位聚合、围栏图形绘制、轨迹折线动画回放等交互能力。

### 亮点 3：轨迹动画回放引擎

> 自主实现轨迹回放控制器，支持播放/暂停/重播/4 档变速/进度拖拽，通过 `setInterval` + 索引驱动地图 Marker 平滑移动，同步更新统计数据与时间标签。

### 亮点 4：AI 语音助手（DeepSeek + 百度语音）

> 小程序端集成 DeepSeek 大模型实现 SSE 流式对话，结合百度语音 STT/TTS 实现语音输入 + 自动朗读，支持连续对话模式（自动录音-识别-发送-朗读循环）。

### 亮点 5：实时通信与告警推送

> 基于 WebSocket 实现按设备分组的会话管理，支持告警、传感器数据、围栏越界、路口辅助等事件的实时推送，管理端顶栏告警铃铛每 15 秒轮询未处理告警。

### 亮点 6：跨端统一架构

> 管理端（Vue 3 + Element Plus）与小程序端（Uni-app + uView Plus）共享同一 Spring Boot 后端 API，小程序端采用 Pinia 状态管理 + 14 个 API 模块分层架构。

### 亮点 7：路口安全通行辅助

> 结合 OpenCV 视觉分析与 WebSocket 实时推送，在小程序端展示红绿灯/斑马线/车辆检测结果，给出智能通行建议（WAIT/GO/CAUTION），支持语音与震动双通道提醒。
