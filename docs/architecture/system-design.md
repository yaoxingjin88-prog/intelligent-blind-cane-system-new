# 系统架构设计

```
│                        客户端层                          │

         │                  │

         │                  │

         │
┌────────┴───────────────────────────────────────────────┐
│                    应用层(Spring Boot)                   │
├──────────────┬──────────────┬──────────────┬───────────┤

         │

         │

├──────────────┬──────────────┬──────────────┬───────────┤

└──────────────┴──────────────┴──────────────┴───────────┘
```

## 技术架构

### 后端技术栈
- **框架**: Spring Boot 3.3.3
- **数据库**: MySQL 8.0
- **ORM**: MyBatis 3.0.3
- **缓存**: Redis 7
- **认证**: JWT (jjwt 0.12.3)
- **文档**: Knife4j 4.5.0
- **WebSocket**: Spring WebSocket
- **定时任务**: Spring Task
- **构建工具**: Maven 3.9.12
- **JDK**: Java 17

### 前端技术栈
- **框架**: Vue 3.3.0
- **构建**: Vite 5.0.0
- **UI**: Element Plus 2.13.7
- **图表**: ECharts 6.0.0
- **路由**: Vue Router 5.0.4
- **状态**: Pinia 2.1.0
- **HTTP**: Axios 1.15.0
- **TypeScript**: 5.0.0

### 小程序技术栈
- **框架**: Uni-app
- **UI**: uView Plus
- **状态**: Pinia
- **地图**: 微信地图/高德地图
- **图表**: ECharts for WeChat

## 模块设计

### 1. 用户认证模块
- **功能**: 登录、注册、权限管理
- **技术**: JWT、Spring Security
- **接口**: `/api/auth/login`, `/api/auth/register`

### 2. 设备管理模块
- **功能**: 设备CRUD、设备状态、设备绑定
- **技术**: MyBatis、WebSocket
- **接口**: `/api/devices/*`

### 3. 传感器数据模块
- **功能**: 数据采集、数据存储、数据查询
- **技术**: MyBatis、Redis缓存
- **接口**: `/api/sensor-data/*`

### 4. 报警管理模块
- **功能**: 报警生成、报警推送、报警处理
- **技术**: WebSocket、定时任务
- **接口**: `/api/alarms/*`

### 5. 电子围栏模块
- **功能**: 围栏CRUD、围栏检测、越界报警
- **技术**: 地理计算、WebSocket
- **接口**: `/api/fences/*`

### 6. 轨迹回放模块
- **功能**: 轨迹存储、轨迹查询、轨迹回放
- **技术**: MyBatis、地图API
- **接口**: `/api/trajectory/*`

### 7. 统计分析模块
- **功能**: 数据统计、报表生成、图表展示
- **技术**: MyBatis、定时任务
- **接口**: `/api/analytics/*`

## 数据流设计

### 设备数据上传流程
```
设备 -> HTTP POST /api/sensor-data -> 后端接收 -> 数据校验 -> 存储MySQL -> Redis缓存 -> WebSocket推送
```

### 报警处理流程
```
传感器数据 -> 规则引擎 -> 触发报警 -> 存储报警记录 -> WebSocket推送 -> 前端展示
```

### 轨迹回放流程
```
前端请求 -> 后端查询MySQL -> 返回轨迹数据 -> 前端地图展示 -> 播放动画
```
